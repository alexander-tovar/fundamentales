Intercambio académico desde la FIME

Esta página corresponde a la AF2 y se construye a partir de un archivo XML. Cada tarjeta se genera con JS leyendo las etiquetas del archivo, así que si cambia el XML, cambia la página.

Incluye dos universidades: una nacional y una internacional. Toca el botón de cada tarjeta para ver sus datos en una ventana emergente.

Cómo está hecho el XML

El archivo tiene una etiqueta raíz y siete etiquetas dentro. Así se ve la estructura de cada universidad:

<universidad id="UNI01">
  <nombre>…</nombre>
  <pais codigo="MX">…</pais>
  <ciudad>…</ciudad>
  <tipo>…</tipo>
  <programa>…</programa>
  <duracion unidad="semestre">…</duracion>
</universidad>
